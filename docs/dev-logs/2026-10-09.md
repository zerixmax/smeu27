## Kronologija izvedenih radnji

### SESIJA 1 — Dijagnoza „Unknown at rule" upozorenja

**Vrijeme:** 09:45 – 09:55  
**Prijava:** u editoru se pojavljivalo upozorenje `Unknown at rule` uz `src/components/Schema.astro`.

#### 1. Provjera build pipelinea — lažna uzbuna
- `npm run check` → **0 errors, 0 warnings, 0 hints** (30 datoteka)
- `astro build` → **7 stranica**, build prolazi bez „Unknown at rule"
- `astro dev` → stranica vraća `200`, dev log čist (bez CSS upozorenja)
- **Zaključak:** upozorenje ne dolazi iz Astro/Vite/Tailwind builda, nego iz **VS Code CSS lintera**.

#### 2. Reprodukcija s `vscode-css-languageservice`
- Iskorišten `vscode-css-languageservice` (već prisutan u `node_modules` kao tranzitivna ovisnost) — to je isti parser koji pokreće VS Code built-in CSS validaciju.
- Rezultat na `src/styles/global.css`:
  - `L3: Unknown at rule @theme`
  - `L35: Unknown at rule @apply`
  - `L54: Unknown at rule @utility`
  - `L61: Unknown at rule @utility`
- Rezultat na `src/components/Schema.astro` i `public/fonts/fonts.css`: **nema** „Unknown at rule" (Schema.astro nema niti jedan `<style>` blok — samo JSON-LD u frontmatteru).
- **Utvrđen pravi izvor:** Tailwind v4 at-rule direktive u `global.css`, koje VS Code CSS linter ne poznaje po defaultu.

#### 3. `.vscode/settings.json` — gašenje lažnih pozitiva
- Dodan novi projektni fajl `.vscode/settings.json`:
  ```json
  {
    "css.lint.unknownAtRules": "ignore",
    "scss.lint.unknownAtRules": "ignore",
    "less.lint.unknownAtRules": "ignore"
  }
  ```
- **Zašto se gasi lint, a ne mijenja kod:** `@theme`, `@utility`, `@apply` su **validne** Tailwind v4 direktive; mijenjati ih ne bi imalo smisla. Upozorenje je isključivo editor-only i ne utječe na build.
- **Zašto projektno, a ne globalno:** postavka vrijedi samo za ovaj workspace i ne dira CSS projekte koji ne koriste Tailwind.
- **Zašto su pokrivena sva tri jezika (css/scss/less):** CSS validacija se u VS Code veže na jezični ID — `.astro` `<style>` blokovi i `.css` datoteke tretiraju se kao `css`, a `scss`/`less` pokrivaju slučaj budućeg `<style lang="scss">`.
